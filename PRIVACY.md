# Privacy

The local demo stores request, work-order, settings, and demo-payment changes in your browser. It does not send them anywhere. Use Settings → Reset demo to remove DwellSignal records without clearing unrelated site data.

A hosted version would handle resident contact details, unit information, maintenance descriptions, access windows, payment status, technician availability, and assignment history. That version must disclose who can see each field, collect only what the workflow needs, set retention periods, provide correction/deletion paths where required, and keep payment card data outside DwellSignal.

Payment timing and maintenance history should not be used as hidden tenant-screening signals. Owners should distinguish building-responsibility issues from resident-responsibility issues and allow corrections.
